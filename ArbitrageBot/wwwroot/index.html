What the bot does

            

              Cross-exchange futures spatial arbitrage.
              Same USDT-M perpetual on several exchanges: LONG the cheaper venue,
              SHORT the richer. Profit when the spread converges — not from predicting price direction.
              No asset transfer on the trade path (inventory / pre-funded balances).
            

            

              Paper mode uses real WebSocket books with virtual margin & fees.
              Live mode is phased (read-only → confirm → small size) with kill switch.

  1. dotnet run → open the URL from the console
    2.

    3.

    4.

    5. 
            
  5. Few trades with strict gates is normal — watch Paper quality & skip reasons
    6. 
          

        


        

          
Recommended settings (effective work)

            paper ≈ intended live rules

          

            

              
ParameterValueWhy

              
                
Min open edge %0.08 – 0.10After open fees; RT still on

                
Quote / notional150 – 200Fits ~2500/venue at 5×

                
Leverage5Controlled inventory

                
Max open3 – 5Start lower while learning

                
Full fill + RT edgeONNo phantom fills / fee blindness

                
FundingONPerp realism

                
Stop / day limit−50 / −150Hard brakes

                
Max hold10 – 15 minSpatial windows are short

                
Depth + persistautoFillable books; anti-flash edge

              
            

          

          

            Do not lower thresholds only to force more trades — that invalidates the lab.
            Settings → Apply updates runtime risk without full restart (starting balance needs Reset paper).
          

        


        

          

            
How to read numbers

            
    
              
  • NET % — edge after open fees (not guaranteed profit)
    • 
              
  • EST $ — idealised if exit were perfect now
    • 
              
  • Unrealized — can be red while waiting for converge
    • 
              
  • width vs entry — wider often hurts the hedge
    • 
              
  • Δ% overlay — cheap → rich mid gap across venues
    • 
              
  • persistWait — edge seen but not held long enough
    • 
              
  • skip reasons — why opens were blocked
    • 
            

          

          

            
Clean history

            
Stop the bot, then:

            
rm -f ArbitrageBot/data/paper/open-state.json
rm -f ArbitrageBot/data/paper/trades-ledger.json
rm -f ArbitrageBot/data/paper/events-*.jsonl
rm -f ArbitrageBot/data/paper/daily-*.json

            
Keep local-settings.json if you need API keys. Then run + Reset paper.

          

        


        

          
Live path (when ready)

          
    
            
  1. Paper days with realistic fees → review win rate & skips
    2. 
            
  2. API keys read-only → Verify balances
    3. 
            
  3. Trade permission, no withdraw; hedge mode + leverage on each exchange
    4. 
            
  4. Live: read-only → confirm phrase → 1 position, tiny notional
    5. 
            
  5. Know KILL SWITCH; scale only if fills match paper assumptions
    6. 
          

        


        

          
Pitch (one paragraph)

          

            ArbitrageBot turns fragmented crypto perpetual prices into a disciplined, measurable
            cross-exchange hedge workflow — live books, depth-aware symbols, fee-aware gates, and a paper lab
            that follows real trading rules. Learn the market. Measure skips and win rate. Only then size live.
