Как работает бот

  1. Discovery — топ пар по объёму/глубине (без BTC/ETH/BNB и токсичных баз), обновление по таймеру.
  2. WebSocket order books — живые стаканы на Binance, Bybit, OKX, Bitget…
  3. Scan (~200–250 ms) — ищет route long→short с gross ≥ порога и net после fees.
  4. Gates — full fill, persist спреда, возраст книги, spreading edge, max ног на venue.
  5. Open hedge — размер = QuoteSize (cap = max notional), плечо, margin на двух биржах.
  6. Exit — take-profit, converge (узкий width), stop-loss, timeout / scalp seconds, orphan prune.

Paper использует реальные стаканы и виртуальный USDT‑margin + fees. Live — поэтапно (read-only → confirm → ордера) с kill switch.

Быстрый старт (Paper)

  1. dotnet run → URL из консоли (часто http://127.0.0.1:5050)
  2. Settings → Торговля: Paper + Авто-исполнение → размер / edge / equity
  3. Сохранить всё — смотри баннер: size $… · max notional $… · reseeded
  4. Если были open-позиции: закрой или Reset paper, снова Save — балансы = Paper starting / Equity
  5. Дождись books > 0, heartbeat; сигналы редкие при жёстких порогах — это норма

Эффективность и ожидания

  • MidΔ на Dashboard — обзор рынка; fee-scored — реальные кандидаты.
  • Мало сигналов при gross ≥ ~0.20–0.28% — нормально на ликвидных альтах.
  • Долгий hold + 4× taker = фабрика минусов; лучше TP / короткий hold.
  • Win rate важнее «частоты сделок». Смотри Reports + skip reasons.

How the bot works

  1. Discovery — top pairs by volume/depth (excludes BTC/ETH/BNB & toxic bases), periodic refresh.
  2. WebSocket order books — live books on Binance, Bybit, OKX, Bitget…
  3. Scan (~200–250 ms) — long→short routes with gross ≥ threshold and net after fees.
  4. Gates — full fill, spread persistence, book age, spreading edge, max legs per venue.
  5. Open hedge — size = QuoteSize (capped by max notional), leverage, margin on both venues.
  6. Exit — take-profit, converge, stop-loss, timeout / scalp seconds, orphan prune.

Paper uses real books with virtual USDT margin & fees. Live is phased (read-only → confirm → orders) with kill switch.

  1. dotnet run → open the console URL
  2. Settings → Trade: Paper + Auto-execute → size / edge / equity
  3. Save all — banner shows size $… · max notional $… · reseeded

  5. Wait for books > 0; few signals under strict gates is normal

  • Few signals at gross ≥ ~0.20–0.28% is expected on liquid alts.
  • Long holds + 4× taker often destroy edge — prefer TP / short hold.
  • Win rate > trade count. Use Reports + skip reasons.
